# ML Service — Личный кабинет (Web/REST/Telegram) + Очереди + Воркеры

Учебный проект: ML-сервис прогнозирования временных рядов с личным кабинетом пользователя.  
Пользователь загружает временной ряд (числовые значения) и задаёт горизонт прогноза (`horizon`).  
Сервис выполняет валидацию входных данных (ошибочные строки возвращаются пользователю), строит прогноз по валидным данным и ведёт учёт списания “кредитов” за успешные запросы.

## Основные возможности (по ТЗ)
- Главная страница с описанием сервиса
- Регистрация и авторизация
- Баланс пользователя в условных кредитах
- Пополнение баланса (без эквайринга)
- Запрос к ML сервису из Web/REST со списанием кредитов при успешном выполнении
- История загруженных данных и предсказаний + сумма списанных кредитов
- REST API и Telegram bot (одинаковая функциональность)
- Валидация данных: ошибки вернуть пользователю, по валидным данным выполнить предсказание
- Проверка положительного баланса перед запуском задачи
- (Опционально) роль админа: модерировать пополнения и смотреть все транзакции

## Архитектурная идея
Запросы на предсказание выполняются асинхронно:
- API создаёт `MLTask` и отправляет её в очередь (RabbitMQ)
- воркеры читают задачи, валидируют данные, выполняют `predict/forecast`, сохраняют `Prediction`
- кредиты списываются при успешном выполнении и фиксируются в `Transaction`
